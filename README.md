# Домашняя аптечка онлайн

Веб-приложение для учёта лекарств в домашней аптечке, отслеживания сроков
годности и формирования списка «отдать до срока» для передачи в приют.

## Назначение

Приложение помогает пользователю:

- вести учёт всех лекарств в доме;
- вовремя замечать препараты с истекающим сроком годности;
- формировать список лекарств, которые можно передать в приют для животных
  или людей, пока они ещё не просрочены;
- быстро находить нужное лекарство по названию или категории.

## Пользовательские сценарии

1. **Просмотр аптечки.** Пользователь открывает главный экран, видит таблицу
   всех лекарств, может искать по названию, фильтровать по категории
   (для людей / для животных) и сортировать по сроку годности.
2. **Добавление лекарства.** Пользователь нажимает «Добавить лекарство»,
   заполняет форму (название, дозировка, форма выпуска, количество в упаковке,
   остаток, срок годности, категория, заметки) и сохраняет запись.
3. **Редактирование и удаление.** Пользователь может изменить данные
   о препарате или удалить его из аптечки.
4. **Список «Отдать до срока».** Пользователь выбирает горизонт (30, 60
   или 90 дней) и видит список лекарств, которые скоро истекут.
5. **Информация о приюте.** Пользователь открывает экран с контактами,
   адресом и списком принимаемых лекарств.

## Экраны

| Маршрут     | Экран           | Назначение                          |
| ----------- | --------------- | ----------------------------------- |
| `/`         | Список лекарств | Просмотр, поиск, фильтрация         |
| `/add`      | Добавление      | Форма создания новой записи         |
| `/edit/:id` | Редактирование  | Форма изменения существующей записи |
| `/donation` | Отдать до срока | Список истекающих лекарств          |
| `/shelter`  | Приют           | Контакты и правила передачи         |

## Стек технологий

- React 19 + TypeScript
- Vite (сборка)
- React Router v7 (клиентская маршрутизация)
- MUI (Material UI) — библиотека UI-компонентов
- ESLint (линтер)

## Запуск проекта

### Требования

- Node.js LTS (20.x или выше)
- npm

### Установка и запуск

```bash
# 1. Установить зависимости
npm install

# 2. Запустить dev-сервер
npm run dev

Приложение будет доступно по адресу http://localhost:5173/.
```
